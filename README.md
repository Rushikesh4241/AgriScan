AgriScan 🌿📱

AgriScan is an AI-powered Android application designed to detect plant leaf diseases using Deep Learning and Computer Vision. The application allows farmers and users to capture or upload leaf images and instantly receive disease predictions along with treatment suggestions for better crop management.

🚀 Features
🌱 Plant Leaf Disease Detection using CNN Deep Learning Model
📷 Capture image from Camera or select from Gallery
🤖 TensorFlow Lite (TFLite) model integration for fast on-device prediction
💊 Disease Treatment & Prevention Suggestions
📊 High Accuracy Image Classification
⚡ Lightweight and Android Optimized
📱 User-Friendly Android Interface
🌐 Offline Prediction Support
🛠️ Technologies Used
Android Studio
Java / Kotlin
TensorFlow & TensorFlow Lite
Convolutional Neural Networks (CNN)
Image Processing
Firebase (optional backend integration)
📂 Project Workflow
User uploads/captures plant leaf image
Image preprocessing is performed
TFLite model predicts disease class
Application displays:
Disease Name
Confidence Score
Treatment Recommendations
🎯 Objective

The main objective of AgriScan is to help farmers and agriculture enthusiasts identify crop diseases at an early stage, reduce crop damage, and improve agricultural productivity using Artificial Intelligence.
